# 曼弗雷德：遗忘实验

> 「我要忘却——」
>
> 「忘却不是我们的本性，而且也不归我们支配。不过——你可以去死。」

**[点灯入场 →](https://jianxing-chen.github.io/manfred/)**　·　建议佩戴耳机　·　全程约十余分钟

---

一八一六年是「无夏之年」。坦博拉火山的尘幕笼罩欧洲，六月飞霜，连绵阴雨把一群英国诗人困在日内瓦湖畔的别墅里读鬼故事。其中那位因丑闻被逐出英国的贵族，在九月走进阿尔卑斯，用十二天写下了两个世纪浪漫主义里最倔强的形象——

他号令过元素与星辰，向宇宙索要的却只有一样东西：**忘却**。精灵给不出，魔女换不来，地狱之王恩准了，而他连恩准也不要。他拒绝天堂，也拒绝地狱；他不忏悔、不下跪，最后像他活着时那样死去——独来独往。

两个世纪后，这个项目把那次失败重做了一遍。

它只有一条规则：**你的任何一次选择都无法改变结局。**这不是缺陷，是主题——正如剧中人无法被救赎，你也无法替他背叛。两个「下跪」按钮在交互上不可能完成：按钮会碎成灰烬，装置替你执行他的拒绝；终幕的「忘却」按钮无论按多少次，永远只回答——我们做不到。

## 六个房间

**一 · [数字装置《遗忘实验》](https://jianxing-chen.github.io/manfred/)**
点灯入场。哥特长廊里应咒而现的七精灵、少女峰悬崖边的致命一步、彩虹雾中的交易、地下殿堂的火球王座、午夜的群魔与终幕落了一夜的雪。雪、雾、虹、灯焰与山脊线全部由代码在浏览器里现场生成；风声、持续低音与 B 小调动机实时合成，无一处采样。

**二 · [虚拟展览《午夜，一盏灯》](https://jianxing-chen.github.io/manfred/exhibition.html)**
策展手册里的九厅方案，建成了一座可以步入的虚拟展馆：售灯处添油领取灯卡，七个声音环绕成环、可以逐一听见并许下请求；一面会碎的镜子、一枚只会重复一句话的按钮、一块跪不下去的跪垫、一间每人一闭的黑屋、一场按得住也按不住的午夜。灯焰随展线逐厅变暗，在第八厅熄灭；雪廊里的每一步都会留下脚印，尽头那颗「忘却」按钮永远不会亮。

**三 · [全文读本](https://jianxing-chen.github.io/manfred/read.html)**
曹元勇译本全文：三幕十场、二百五十二段台词、二十二条注释，朱丝栏古典排版，联动目次随阅读位置点亮。装置与展览里的每一句台词都出自这里。

**四 · [解读文集](https://jianxing-chen.github.io/manfred/essays.html)**
六篇长文，从六个方向逼近那盏午夜的油灯：遗忘作为一种不可能的请求；无法言说的罪与不可转交的灵魂；无夏之年与崇高的诞生地；舒曼、柴可夫斯基与尼采为它写下的音乐（以及一次著名的惨败）；拜伦式英雄的两百年谱系；还有一位译者与他的八十年代午夜。

**五 · [档案馆](https://jianxing-chen.github.io/manfred/atlas.html)**
一个文本漂流两百余年的行李清单：影响年表、一张把阿里曼涅斯殿堂刻意画在图框之外的阿尔卑斯地图书、人物志、概念词典、逐句核对的中英双语对照，以及勃兰兑斯与歌德的判词。

**六 · [策展手册《午夜，一盏灯》](https://jianxing-chen.github.io/manfred/installation.html)**
一场假想实体展览的完整方案：九个展厅、一块跪不下去的跪垫、一盏随动线逐厅变暗的灯、一个按不亮的「忘却」按钮——以及把这一切装进浏览器的全部技术说明。它已不再是假想：方案本身即上一座虚拟展览的图纸。

## 出发点

歌德的浮士德求知识，曼弗雷德求忘却——欧洲浪漫主义精神地图的两极。勃兰兑斯说，曼弗雷德「同天堂和地狱都一样无缘，他是他自己的起诉人和审判官」。这个项目不想展示拜伦，它想让你替曼弗雷德走一遍那条路——并且让他失败。带着全部记忆离开，就是全部的意义。
