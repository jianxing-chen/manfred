# 设计文档：《曼弗雷德：遗忘实验》 — 以拜伦诗剧《曼弗雷德》为锚点的多形态数字项目

## 1. 缘起与锚点

拜伦《曼弗雷德》（1816–1817，三幕诗剧，本项目所用中译为曹元勇译本，收录于《曼弗雷德 该隐：拜伦诗剧两部》）。主人公曼弗雷德背负无法言说的罪（挚爱的阿丝塔忒之死），向宇宙中的一切力量只求一样东西：**忘却**。精灵、魔女、命运女神、地狱之王、修道院长老——没有任何力量能够给予遗忘，也没有任何力量能使他跪下。他拒绝天堂，也拒绝地狱，最终以自己的方式死去："老人家！要死并不太难啊！"

## 2. 发散与收敛

候选方向：A. 沉浸式网页数字装置；B. 文字冒险游戏；C. 生成音乐专辑（致敬柴可夫斯基《曼弗雷德交响曲》）；D. 实体展览策展方案；E. 影响关系可视化/档案。

**决定：A 为主干，吸收 B/C/D/E 为子模块。** 理由：唯一能同时容纳"游戏/装置艺术/解读/分析/拓展"全部形态的载体；纯静态、无构建依赖、离线可运行；与我可直接验证（浏览器实测）的交付链一致。

## 3. 核心艺术概念

**「遗忘——唯一求而不得之物」。整个装置被框架为一次注定失败的"遗忘实验"。**

- 叙事引擎的"交互动词"不是得到，而是**拒绝**：访客的选择要么被曼弗雷德代言的拒绝覆盖，要么失败。
- 关键场景的背叛选项（向魔女/阿里曼涅斯下跪）**在交互上不可能完成**——按钮会散成灰烬，装置替你执行曼弗雷德的拒绝。这是本作的元命题：你无法替他背叛。
- 贯穿道具：**一盏油灯**（开场第一句"这盏孤零的油灯必须把油漆满"）。灯既是进度指示，也是装置的"生命"。终幕灯熄，接入尾声。
- 结尾的"遗忘"按钮永远返回失败："我们做不到。——七个精灵"。访客被留在与曼弗雷德相同的位置：带着一切，独自下山。

## 5. 技术方案

- 纯静态站点，零构建、零外部依赖（离线 file:// 可运行）→ 数据用 JS 文件（`window.XXX`）而非 fetch JSON。
- `assets/js/data-manfred.js`：由 `tools/parse_manfred.py` 从 epub 提取文本解析生成的结构化全文（幕/场/台词/舞台指示/注释）。
- `assets/js/data-quotes.js`、`data-timeline.js`、`data-characters.js`、`data-concepts.js`、`data-essays.js`：手工策展数据。
- `assets/js/audio.js`：Web Audio 生成音景引擎。分层：风（带通噪声 LFO）/ 持续低音（失谐振荡器，各幕换调）/ 动机音序（每幕一个 B 小调系动机）/ 钟、合唱垫、心跳脉冲。双延迟反馈网络做混响。首次用户手势后启动，常驻开关。
- `assets/js/scenes.js`：Canvas 2D 场景渲染器（种子化噪声山脊线、星空/月、雨雪粒子、彩虹瀑布、火球王座、灯焰）。`prefers-reduced-motion` 降级。
- `assets/js/installation.js`：幕次状态机 + 文字动态排版 + 交互（含"跪"按钮的灰烬化）。
- `assets/css/`：`installation.css`（装置专用，全屏黑场）与 `site.css`（阅读/档案/文集共用的纸感排版）。
- 中文衬线字体栈：`"Noto Serif SC","Songti SC","STSong","SimSun",serif`；装置内标题可用衬线+大字距。

## 7. 写作计划（文集 6 篇，每篇 1200–2500 字）

1. 《我要忘却：一种不可能的请求》— 与浮士德对读（求知识 vs 求遗忘）；"知识的树不是生命的树"。
2. 《无法言说的罪，不可转交的灵魂》— 阿丝塔忒、沉默作为回答、拒绝忏悔的伦理。
3. 《一八一六：无夏之年与高山》— 坦博拉、迪奥达蒂别墅、阿尔卑斯之旅、崇高美学、 genesis。
4. 《为曼弗雷德谱曲的人们》— 舒曼 Op.115、柴可夫斯基 Op.58（巴拉基列夫提案、四乐章与诗剧对位）、歌德的赞誉与勃兰兑斯的逆评。
5. 《拜伦式英雄及其后裔》— 从普罗米修斯/该隐到皮却林、弗兰肯斯坦、尼采、地下室人，再到现代反英雄。
6. 《译者与他的午夜》— 曹元勇后记、"西绪福斯式的英雄"、翻译作为块垒的浇灌。
